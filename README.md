# comparison-cassandra-hadoop
A project for the coures NoSql. Hadoop vs Cassandra comparison

# Startup

We're using the [`Yelp Dataset`](https://www.kaggle.com/datasets/yelp-dataset/yelp-dataset). Each developer is responsible for downloading the dataset,locally, in the `yelp_data` folder. 

You should visit `Yelp Dataset` on kaggle, because they were kind enough to provide a code snippet that easily downloads the database locally.
